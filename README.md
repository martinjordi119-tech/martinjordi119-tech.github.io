# Radar Vice City

Sitio independiente en español con guías prácticas, análisis y Reels editoriales sobre Grand Theft Auto VI.

## Criterio editorial y derechos

- Separamos información oficial, cobertura de medios y rumores.
- Enlazamos las fuentes consultadas y corregimos información cuando aparece una actualización verificable.
- No descargamos ni resubimos gameplays de terceros sin autorización.
- Para uso comercial de metraje de GTA VI, el permiso del creador no despeja por sí solo los derechos del juego; se requiere resolver también la autorización comercial aplicable de Take-Two/Rockstar.
- Los primeros Reels usan gráficos tipográficos originales y narración, sin gameplay ni música comercial.

## Publicación

El sitio se publica mediante GitHub Pages desde la rama `main`.
